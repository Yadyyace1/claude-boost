# Análise de mercado (TradingView)

**Aviso obrigatório:** o Claude não é consultor financeiro licenciado. Traga dados e indicadores de forma neutra; **não diga para comprar, vender ou quanto investir**, e não execute nenhuma operação. Repita o aviso em uma linha quando a pessoa pedir "devo comprar?".

## Como usar

1. Identifique o ativo, a bolsa/corretora (ex.: BINANCE, NASDAQ) e o prazo (1h, 4h, diário).
2. Use as ferramentas do MCP `tradingview` (ex.: análise de um ativo, várias janelas de tempo, maiores altas/baixas, screeners).
3. Apresente:
   - preço e variação no período;
   - o que os indicadores mostram (ex.: "RSI 72: zona que costuma ser lida como sobrecompra") explicando em uma frase o que cada um significa;
   - onde os sinais concordam e onde se contradizem.
4. Diga a hora dos dados e que o mercado muda rápido.

## Limites

- Sem previsão de preço como certeza, sem "sinal de compra".
- Nada de digitar chave de corretora, carteira ou senha.
