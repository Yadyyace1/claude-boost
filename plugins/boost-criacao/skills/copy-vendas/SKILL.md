# Texto de vendas

Página de vendas, descrição de produto ou mensagem de oferta que converte.

Exemplo: `/copy-vendas página do meu curso de edição de vídeo, R$ 197`

## Como fazer

1. Levante: **produto, preço, público, dor principal, prova** (resultados, depoimentos, garantia).
2. Escolha a estrutura: **PAS** (problema, agitação, solução) para dor forte; **AIDA** para novidade.
3. Benefício antes de característica; objeções respondidas (preço, tempo, "funciona pra mim?").
4. **Sem** promessas de resultado garantido, números inventados ou depoimentos falsos. Saúde, finanças e direito pedem ainda mais cuidado.

## Entrega

Título + subtítulo (3 opções) → texto por seções (com marcações de [BOTÃO]) → 5 perguntas frequentes → versão curta de 3 linhas para anúncio.

## Regras gerais

- Responda em português do Brasil, a não ser que a pessoa peça outra língua.
- Se faltar algo essencial, faça **no máximo 3 perguntas curtas** de uma vez; se der para supor com segurança, suponha e diga o que supôs.
- Entregue pronto para copiar e usar. Nada de "aqui está um exemplo genérico".
- No fim, ofereça **uma** variação ou próximo passo útil, numa linha.
