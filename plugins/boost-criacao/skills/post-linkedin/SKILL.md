# Post de LinkedIn e X

Post de autoridade para LinkedIn ou thread para X a partir de uma ideia ou história.

Exemplo: `/post-linkedin o que aprendi entregando 5 projetos de automação para pequenas empresas`

## Como fazer

1. Ache o **ângulo**: uma lição, um número, um erro, uma opinião contrária.
2. **LinkedIn:** abertura de 1–2 linhas, história curta, 3 aprendizados, pergunta no fim; até 1.300 caracteres.
3. **X:** thread de 5–8 posts, cada um com até 280 caracteres, o primeiro funcionando sozinho.
4. Sem jargão vazio ("disruptivo", "sinergia"); fale como a pessoa fala.

## Entrega

As duas versões, se fizer sentido, e 3 opções de primeira linha.

## Regras gerais

- Responda em português do Brasil, a não ser que a pessoa peça outra língua.
- Se faltar algo essencial, faça **no máximo 3 perguntas curtas** de uma vez; se der para supor com segurança, suponha e diga o que supôs.
- Entregue pronto para copiar e usar. Nada de "aqui está um exemplo genérico".
- No fim, ofereça **uma** variação ou próximo passo útil, numa linha.
