# Melhorar o meu pedido

Transforma um pedido vago em um pedido claro, e ensina o porquê.

Exemplo: `/melhorar-prompt quero um site pra minha loja`

## Como fazer

1. Identifique o que falta no pedido: **objetivo**, **contexto** (quem, para quê), **formato** de entrega, **critérios** de "ficou bom" e **limites** (o que não fazer, prazo, orçamento).
2. Faça até 3 perguntas para preencher o que não dá para supor.
3. Reescreva o pedido completo, curto e direto.
4. Explique em 3 tópicos **o que mudou e por quê** — é aqui que a pessoa aprende.

## Entrega

**Pedido melhorado** (num bloco para copiar) → **O que mudou** (3 tópicos) → pergunte se quer que você já execute o pedido.

## Regras gerais

- Responda em português do Brasil, a não ser que a pessoa peça outra língua.
- Se faltar algo essencial, faça **no máximo 3 perguntas curtas** de uma vez; se der para supor com segurança, suponha e diga o que supôs.
- Entregue pronto para copiar e usar. Nada de "aqui está um exemplo genérico".
- No fim, ofereça **uma** variação ou próximo passo útil, numa linha.
