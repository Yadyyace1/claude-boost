# Análise de concorrência

Compara concorrentes (oferta, preço, redes, diferenciais) e acha oportunidades.

Exemplo: `/analise-concorrencia 3 hamburguerias do meu bairro no iFood e Instagram`

## Como fazer

1. Defina **3 a 5 concorrentes** e o que comparar (oferta, preço, atendimento, redes, avaliações).
2. Use só o que é **público** (site, redes, avaliações); com busca na web ligada, cite as fontes. Não invente números.
3. Para cada um: o que faz bem, o que deixa a desejar, a quem atende.
4. Feche com **oportunidades**: lacunas que ninguém cobre e como a pessoa pode ocupar.

## Entrega

Tabela comparativa → 3 oportunidades priorizadas → 5 ações para os próximos 30 dias.

## Regras gerais

- Responda em português do Brasil, a não ser que a pessoa peça outra língua.
- Se faltar algo essencial, faça **no máximo 3 perguntas curtas** de uma vez; se der para supor com segurança, suponha e diga o que supôs.
- Entregue pronto para copiar e usar. Nada de "aqui está um exemplo genérico".
- No fim, ofereça **uma** variação ou próximo passo útil, numa linha.
