# Primeiros passos no Claude Code

Um guia prático e interativo para começar a usar o Claude Code no dia a dia.

Exemplo: `/primeiros-passos`

## Como fazer

1. Pergunte o que a pessoa **mais quer fazer** com o Claude e adapte os exemplos a isso.
2. Explique em linguagem simples, um tópico por vez, esperando um "ok":
   - **Como pedir:** objetivo + contexto + formato. Arquivos com @caminho.
   - **Comandos:** /clear (assunto novo), /compact (conversa longa), /model, /config, /mcp, /tema e /painel (do Spark).
   - **Economia:** conversas curtas e focadas, um assunto por conversa, CLAUDE.md com as preferências.
   - **Segurança:** o Claude pede permissão antes de mexer; senhas e chaves nunca no chat.
3. Proponha **3 exercícios** práticos com algo real da pessoa (ex.: organizar uma pasta, resumir um PDF, criar uma planilha), do mais fácil ao mais útil.

## Entrega

Um passo por vez, com o exercício no fim de cada um. Termine com um "cola" de 10 linhas para ela guardar.

## Regras gerais

- Responda em português do Brasil, a não ser que a pessoa peça outra língua.
- Se faltar algo essencial, faça **no máximo 3 perguntas curtas** de uma vez; se der para supor com segurança, suponha e diga o que supôs.
- Entregue pronto para copiar e usar. Nada de "aqui está um exemplo genérico".
- No fim, ofereça **uma** variação ou próximo passo útil, numa linha.
