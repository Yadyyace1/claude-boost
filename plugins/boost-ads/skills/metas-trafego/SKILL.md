# Metas de tráfego

Antes de olhar qualquer campanha, a pessoa precisa saber **quanto pode pagar** por um resultado sem perder dinheiro. Esta skill calcula isso.

## 1. Perguntar (o que faltar)

- **Ticket médio** (valor de uma venda). Se houver recompra, o valor médio por cliente em 6 a 12 meses.
- **Custo por venda** (produto, frete, taxas, comissão, imposto) ou a **margem** em %.
- **Taxa de fechamento:** de cada 100 leads (ou conversas no WhatsApp), quantos compram.
- **Meta de lucro** por venda depois do anúncio (opcional; sem ela, o cálculo é o ponto de equilíbrio).
- **Meta de vendas** no mês, ou o orçamento disponível.

## 2. Fórmulas

Mostre sempre a conta, não só o resultado:

- **Lucro bruto por venda** = ticket − custos (ou ticket × margem).
- **CPA máximo** (ponto de equilíbrio) = lucro bruto por venda. Com meta de lucro: lucro bruto − lucro desejado.
- **ROAS de equilíbrio** = ticket ÷ CPA máximo (quando o CPA máximo é o lucro bruto inteiro, isso vira 1 ÷ margem). Abaixo dele, cada venda dá prejuízo.
- **CPL alvo** = CPA máximo × taxa de fechamento dos leads.
- **Custo máximo por conversa** (WhatsApp) = CPA máximo × taxa de fechamento das conversas.
- **Orçamento mensal** = vendas desejadas × CPA alvo.

Exemplo curto: ticket R$ 300, margem 50% → lucro bruto R$ 150 → CPA máximo R$ 150 → ROAS de equilíbrio 2,0. Se 10% dos leads compram, o CPL alvo é R$ 15.

## 3. Três cenários

Monte uma tabela com:

| Cenário | Premissa | CPA | Vendas no orçamento | Resultado |
|---|---|---|---|---|
| Conservador | conversão pior que a esperada, CPA perto do máximo | | | |
| Base | as taxas que a pessoa informou | | | |
| Otimista | conversão melhor, CPA bem abaixo do máximo | | | |

Use variações razoáveis (por exemplo, taxa de fechamento −30% e +30%) e diga quais foram.

## 4. Entregar

- A tabela das metas (CPA máximo, ROAS de equilíbrio, CPL, custo por conversa).
- Os 3 cenários.
- Um aviso honesto quando a conta não fecha (ticket baixo demais para anúncio pago, por exemplo) e o que mudaria isso: aumentar ticket, oferta de entrada, recompra, melhorar a conversão.

## Cuidados

- Números de taxa de fechamento chutados geram metas erradas. Se a pessoa não sabe, use uma estimativa marcada como **chute** e sugira medir nas primeiras semanas.
- É cálculo de meta, não promessa de resultado.
