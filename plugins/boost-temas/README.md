# boost-temas

```
/plugin install boost-temas --marketplace Yadyyace1/spark
```

Temas do Spark para o app do Claude (desktop e celular): sete visuais completos, cada um com modo claro e escuro, menos o Synthwave, que é só escuro.

| Tema | Clima |
|---|---|
| `ambar` | Quente e acolhedor: madeira, cobre e luz de abajur |
| `synthwave` | Neon dos anos 80, com pôr do sol e grade em movimento (só escuro) |
| `floresta` | Verdes calmos de mata e musgo |
| `oceano` | Azuis profundos, com ondas lentas ao fundo |
| `caderno` | Papel de dia e papel à luz de abajur à noite |
| `grafite` | Neutro e minimalista |
| `royal` | Azul royal com pêssego |

Para trocar, digite `/tema oceano`; só `/tema` lista os temas. A escolha fica salva para as próximas sessões. Pelo `/config` dá para escolher o tema e ligar ou desligar o cenário animado. O terminal não desenha temas: eles aparecem no app.

Todas as paletas passam no verificador de contraste do app, e os cenários são vetoriais, lentos e param para quem pede menos movimento.
